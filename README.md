One line of awkward small talk that one robot says to another while they ride an elevator together: it simulated this exact ride 4,096 times and still forgot to ask which floor the other robot wanted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
